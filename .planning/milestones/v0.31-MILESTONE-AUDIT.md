# v0.31 Milestone Audit — SVG Numeric Boundary Unification

## Verdict: PASSED

All three v0.31 requirements are satisfied. The earlier audit's sole blocker — a
manually built `Group` publishing an unchecked `PushTransform(65537)` — is
closed in the current implementation. The lowerer now carries an admitted
inherited affine through both `Svg` and `Group` traversal and uses the Phase 95
shared `checked_compose_affine` seam before emitting or propagating a local
transform. An unsafe manual composition emits identity and retains the last
safe parent state; unsafe parsed source still returns `Err(CoreError)` before
a `SceneNode`, drawing list, or raster operation can be published.

## Resolution of the previous audit blocker

The superseded audit recorded `lower_node(Group)` directly publishing its local
transform without validating its composition with ancestor state. That is no
longer true:

| Previous failure | Current end-to-end trace | Status |
|---|---|---|
| Nested manual `translate(65536)` then `translate(1)` published an unsafe effective affine. | `lower_to_drawing_list` starts at identity (`lower.mbt:33-36`); `Group` calls `checked_compose_affine(current, transform)` (`:71-78`). The failed inner composition emits identity and recurses with the safe outer state (`:77-94`). `lower_wbtest.mbt:856-898` checks the seam error and both actual lowerer runs, including transform/layer/pop order. | **CLOSED** |
| A valid viewBox map plus finite Group transform could bypass inherited admission. | `Svg` first composes its map into child state (`lower.mbt:47-69`); its Group child is then checked against that state. `lower_wbtest.mbt:900-946` checks map `65536` plus local scale `2` twice and requires an identity Group transform. | **CLOSED** |
| Parsed unsafe Group source could differ from total-lowerer behavior. | `parse_svg` only returns `Ok(node)` after `preflight_scene` (`scene.mbt:207-217`), where both `Svg` and `Group` call `checked_compose_affine` (`:264-280`). `svg_test.mbt:148-192` asserts structured parser errors for unsafe and nested Group input. | **CLOSED** |

The former direct-`PushTransform(65537)` test sentinel has been replaced by
the inherited-affine recovery tests above. The Phase 96-03 RED/GREEN records
and fresh all-target gate corroborate the live trace; no production behavior
is inferred from test existence alone.
