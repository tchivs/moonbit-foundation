## Recorded Technical Debt

The parser-side preflight intentionally mirrors some lowerer geometry arithmetic. It prevents unsafe parser-produced scenes before lowering, while the lowerer remains total for manually constructed public `SceneNode` values. Current behavior is fully covered, but future lowerer arithmetic changes need a paired preflight update and cross-check to prevent drift. This is a non-blocking maintenance item, not a current integration failure.
