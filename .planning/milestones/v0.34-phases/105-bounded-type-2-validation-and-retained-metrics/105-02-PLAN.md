<edge_assumptions>
1. A-01: The operand stack is shared across explicit root/local/global frames; transient and PRNG state are per glyph.
2. A-02: Uninitialized transient get is Data; put marks exactly one element initialized.
3. A-03: Masks require at least one stem and consume ceil(stems/8) raw bytes after pending vertical stems.
4. A-04: Subroutine endchar legally terminates only a tail-call chain; ordinary subroutines return explicitly.
5. A-05: Unknown/reserved Type 2 operators are Data, CFF2-only operators Capability, dotsection a no-op, seac Capability.
6. A-06: Error ordering is State/revision → Resource → Capability → encountered Data.
7. A-07: Repeated subroutine bytes are charged on execution even though source storage bytes are not double-counted.
</edge_assumptions>
