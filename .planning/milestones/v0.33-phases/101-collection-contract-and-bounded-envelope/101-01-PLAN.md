## Security Profile

OWASP ASVS L1 applies at the caller-bytes-to-parser trust boundary. The configured block threshold is high; every high-severity threat below is mitigated and owned by an automated task gate.

## Trust Boundaries

| Boundary | Description |
|---|---|
| caller `ByteView` -> `FontCollection::open` | Untrusted bytes and counts cross into collection authority. |
| private parser facts -> public facade | Only bounded semantic facts may cross; storage identity remains private. |
| retained mutable backing -> cached query facts | Revision drift must invalidate all cached facts before publication. |
| generated interface -> downstream callers | The new public ABI must be exact and additive. |
