<threat_model>
## ASVS Profile

OWASP ASVS L1 applies. Authentication, sessions, access control, and cryptographic authenticity are outside this byte-parser boundary. SFNT checksums are format integrity fields, not authentication.

## Trust Boundaries

| Boundary | Description |
|---|---|
| caller bytes → `Font::open` | Attacker-controlled lengths, counts, offsets, tags, and table data enter the portable parser |
| caller limits/budget → admission coordinator | Caller-owned ceilings and mutable budget govern parser work and must not be bypassed by font declarations |
| retained backing → public query | Caller mutation can invalidate previously admitted table windows and cached facts |
| private facts → public `Font` | Partial or inconsistent parser state must never cross the publication boundary |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-97-01 | Tampering | `cursor.mbt`, `directory.mbt` offsets/counts | high | mitigate | Checked widened arithmetic and contained table-local `ByteView` windows before reads; exact-fit/one-short and overflow tests block completion. |
| T-97-02 | Denial of Service | declared table/count/checksum work | high | mitigate | Intersect declarations with `FontLimits`, derive work safely, and charge one atomic `Budget` transaction; boundary tests block completion. |
| T-97-03 | Tampering | retained source after admission | high | mitigate | Capture the opening revision, compare before `Font` publication, guard every query, and test mutation plus mutate-back. |
| T-97-04 | Tampering | private facts → public `Font` | high | mitigate | One coordinator and one final construction expression after all tracer checks; failure tests prove no partial public value. |
| T-97-05 | Information Disclosure | structured parser errors | low | accept | Errors expose bounded offsets/counts and stable tokens only; font bytes contain no repository secret, and rendered prose is not a compatibility surface. |
| T-97-06 | Elevation of Privilege | host/FFI capability leakage | low | accept | Pure MoonBit package has no host, filesystem, FFI, or platform-font dependency; generated interface review verifies the boundary. |
