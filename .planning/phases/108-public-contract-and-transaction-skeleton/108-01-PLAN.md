<interfaces>
Existing authorities the tracer extends:
- `ResourceCharge` is opaque in `modules/mb-core/budget/budget.mbt`; consumable dimensions are bytes/allocations/pixels/work and ceiling dimensions are allocation_size/width/height.
- `Budget::preflight(charge)` checks all ancestor windows without mutation; `Budget::charge(charge)` re-preflights then mutates every window atomically.
- `Font` retains its source and opening revision in `modules/mb-font/font/font.mbt`; guarded publication patterns perform `before_final_guard`, compare revision, then charge.
- `FontLimits` in `modules/mb-font/font/limits.mbt` is the validated-private-field pattern for `ShapeLimits`.
- The compile-proved seam is exactly `Font::with_shape_transaction[T](self : Font, budget : @budget.Budget, body : (FontShapeScope) -> Result[(T, @budget.ResourceCharge), @error.CoreError]) -> Result[T, @error.CoreError]`. `FontShapeScope` is public-abstract and externally unconstructable. Generic `T` can nominally return the scope, so `defer`-driven shared-cell invalidation—not static lifetime enforcement—makes every post-callback operation fail with `State` / `InvalidRange`, operation `font-shape-scope`, context `font-shape-scope-closed`.
- The Phase 108 `ShapeLimits` interface is exactly `ShapeLimits::new(max_input_scalars~ : UInt64, max_output_glyphs~ : UInt64) -> Result[ShapeLimits, @error.CoreError]`, `ShapeLimits::max_input_scalars(self : ShapeLimits) -> UInt64`, and `ShapeLimits::max_output_glyphs(self : ShapeLimits) -> UInt64`; both values are nonzero and no default or additional limit group is public.
