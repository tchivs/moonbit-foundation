## ASVS L1 Applicability and Threshold

This is a pure bounded-binary utility with no external API surface. Apply ASVS L1 validation, resource-safety, and atomic-result principles. Every high or critical threat is mitigated; lower-severity acceptance requires deterministic evidence. No package installation occurs.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| typed CFF facts → keying adapters | Attacker-controlled charset, Encoding, ROS, FDArray, and FDSelect facts select retained environments. |
| per-GID selection → descriptor set | A malformed late glyph or unused FD must not leave a partial descriptor set. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-104-05 | Tampering | SID/CID and charset resolution | high | mitigate | Validate complete ranges/cardinality and resolve SIDs through one bounded standard-plus-String domain. |
| T-104-06 | Elevation of Privilege | FDSelect environment selection | high | mitigate | Accept only formats 0/3, validate all ranges/sentinel/FD references, and materialize one private descriptor per GID. |
| T-104-07 | Denial of Service | Range expansion and FDArray validation | high | mitigate | Exact preflight and limits precede traversal and allocation; validate compact ranges instead of expanded attacker-sized copies where possible. |
| T-104-08 | Repudiation | Multi-fault keying errors | medium | accept | Stable stage precedence and exact/one-short tests make the selected failure reproducible. |
</threat_model>
