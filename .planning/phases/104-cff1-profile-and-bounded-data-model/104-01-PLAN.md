2. A-02: Standalone and selected TTC/OTC table records remain SFNT-root-relative; every CFF-internal offset is table-relative only after one checked `'CFF '` window exists.
3. A-03: The FontSet has exactly one Name INDEX object and one Top DICT object; empty INDEX encoding is exactly its count field.
4. A-04: INDEX offsets are 1-based from object data, accept `offSize` 1 through 4, begin at 1, and are monotonic and in range after terminal-extent proof.
5. A-05: DICT integers, reals, and escaped forms become checked rational/fixed structural values without `Double`; reserved, truncated, non-finite, or derived out-of-range values fail.
6. A-06: Top, Font, and Private DICT schemas have exact arity, defaults, named offset bases, and rejection of duplicate structural singleton operators.
7. A-07: `maxp.numGlyphs` equals CharStrings INDEX count, so OpenType GID is exactly the CharStrings object position.
8. A-08: A complete parse, validation, exact preflight, final revision check, and one budget commit precede publication of private admitted facts; failure publishes and charges nothing.
</edge_assumptions>
