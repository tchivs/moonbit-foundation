## Trust Boundaries

| Boundary | Description |
|---|---|
| caller ByteView -> SFNT admission core | Untrusted binary offsets, lengths, counts, tags, checksums, and table payload declarations cross into portable parser code. |
| admitted private facts -> public Font | Only mutually consistent, limit-checked, revision-stable facts may become queryable public state. |
| retained mutable backing -> public metric query | Caller-visible backing storage may change after admission even though the library retains its ByteView. |
