<threat_model>
## Security Level

OWASP ASVS L1 applies. The primary trust boundaries are hostile caller bytes entering the private metric parser, caller-controlled GlyphId values crossing the public query API, and retained caller storage changing after admission.

## Trust Boundaries

| Boundary | Description |
|---|---|
| caller bytes -> admitted hmtx/loca/glyf facts | Untrusted offsets, counts, signed fields, and table lengths influence reads and work. |
| caller mutation -> retained Font queries | The backing ByteView may change after the admission transaction. |
| public GlyphId -> receiving Font | An opaque ID can originate from another Font and still requires receiving-font range validation. |
| generated interface -> consumers | Accidentally public private descriptors or deferred APIs become compatibility surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-97-03-01 | Tampering | hmtx/loca/glyf lookup in `metrics.mbt` | high | mitigate | Use checked widened cardinality/index/range arithmetic, normalized table-local ByteViews, monotonic loca validation, and ten-byte non-empty header containment before reads. |
| T-97-03-02 | Denial of Service | declared glyph/count/work values during admission | high | mitigate | Intersect declarations with FontLimits and atomic shared Budget charges before count-driven validation or allocation; test exact and one-short limits. |
| T-97-03-03 | Tampering | retained ByteView after Font publication | high | mitigate | Compare mutation revision before every Font query and again before publishing source-derived metrics; test unrelated mutation and mutate-back. |
| T-97-03-04 | Tampering | GlyphId supplied to a different Font | medium | mitigate | Keep construction opaque and revalidate the numeric value against the receiving Font before metric indexing. |
| T-97-03-05 | Information Disclosure | public generated `.mbti` | medium | mitigate | Exact policy allowlist prevents private table/window descriptors, raw offsets, and deferred capability types from becoming public. |
| T-97-SC | Tampering | package/dependency resolution | low | mitigate | Add no package install; use frozen MoonBit commands and policy-enforce `tchivs/mb-core` as mb-font's only runtime dependency. |

</threat_model>
